A one-line museum placard for an ordinary office object, written as if it
were an ancient artifact. The subject is the whiteboard itself — the
meeting room's own relic, still bearing last quarter's targets in a hand
no one can read, for a product no one sells.

## Run

```sh
python3 main.py
```

Writes the placard to `output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
`main.py` validates the entry before writing: exactly one line, 1–180
characters, valid UTF-8, no leading or trailing whitespace, no control
characters.

## The entry

> Whiteboard, c. 2011. Its surface still bears last quarter's targets, in a hand no one can read, for a product no one sells. Gift of the Strategy Offsite.
